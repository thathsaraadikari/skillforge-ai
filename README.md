# 🔥 SkillForge AI

> AI-powered career development platform that turns your skills into a personalized roadmap to your dream job.

## 🚀 Features
- 🎯 Skill Gap Analysis
- 🗺️ Personalized Learning Roadmap
- 📁 GitHub Repository Analyzer
- 📄 CV & ATS Optimizer
- 🤖 AI Mentor Chat
- 📊 Job Readiness Score
- 💡 Portfolio Project Generator

## 🛠️ Tech Stack
- **Frontend**: React + Vite + TypeScript
- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL
- **AI**: OpenAI / Gemini API
- **Auth**: JWT + GitHub OAuth
- **DevOps**: Docker + Docker Compose

## 🏗️ Status
🚧 In active development — built as a learning portfolio project.
